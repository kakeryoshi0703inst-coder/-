# メモっとく？
## ― 掃除や買い物、定期ルーティンを「最後にいつ行ったか」すぐ確認・記録するアプリ ―

---

## 🌟 アプリの概要

「お風呂掃除、最後にやったのいつだっけ？」  
「トイレットペーパーや洗剤、いつ買い足した？」  
「シーツや枕カバー、何日洗ってない？」  

日常の掃除・買い物・メンテナンス・消耗品交換など、**「最後にいつやったか」をパッと確認し、タップして詳細を開いてから「今やった！」と確実に記録できる**、スマートフォンに最適化された自分専用のWebアプリです。

---

## 📱 スマホに特化したUI/UXの特徴

1. **一目でいつ行ったのかが分かる「📅 カレンダー」欄**
   - 画面上部のタブ（`📋 項目リスト` / `📅 カレンダー`）でワンタップ切り替え。
   - カレンダー上の日付セルに、実施した活動（掃除＝緑、買い物＝オレンジなど）の**カラフルなインジケータードット**を表示。
   - 日付をタップすると、その日に完了した行動一覧（タイトル、時刻、メモ）を即座に確認できます。
   - 月間サマリーで今月の合計実施回数やカテゴリ別の内訳も一目で把握可能。

2. **枠を超えない最適化UI & ごみ箱アイコンによる破棄・削除**
   - 項目追加・編集モーダルの下部ボタンを、枠（コンテナ境界）をはみ出さないようにレスポンシブ調整。
   - 「キャンセル」ボタンをごみ箱アイコン（🗑️）に変更。新規追加時は下書きの破棄、既存項目編集時は確認付きの削除ボタンとして直感的に操作できます。

3. **誤操作を防ぐ「詳細を開いてから記録」設計**
   - 一覧のカードをタップすると詳細画面が開き、実施日時やメモ（例:「防カビくん煙剤も使った」「2袋まとめ買い」）を確認・入力した上で「✨ 今やった！」を押して記録。誤タップによる誤更新を防ぎます。

4. **柔軟な「次の作業目安日」の入力 & 自動計算連携（NEW✨）**
   - 新規作成・編集モーダルで、**次回の作業目安日をカレンダーピッカーから直接手動入力**可能。
   - 「今日」「明日」「3日後」「1週間後」「2週間後」「1ヶ月後」の**クイックチップ**をワンタップするだけで素早く日付指定。
   - 「周期から自動計算」ボタンで、前回実施日（または今日）＋目標周期から目安日を瞬時に算出。
   - **詳細画面から直接目安日のクイック変更・解除**が可能（わざわざ編集画面を開く手間が不要）。
   - 一覧カードにも「⏰ 次回目安: 10/20 (あと3日)」と明瞭に表示。
   - 「次回目安が近い順」でのソート機能を追加。
   - カレンダー上にも作業目安日がある日にインジケーター（マーカー）が表示され、タップするとその日の目安項目一覧が把握可能。

5. **推奨周期とステータス表示**
   - 各項目に「1週間ごと (7日)」「2週間ごと (14日)」「1ヶ月ごと (30日)」などの目安ペースを設定可能（周期なしも可）。
   - 経過日数や目安日に応じて、一目で優先度がわかるバッジを表示：
     - 🔴 **期限超過**: 「3日超過」
     - 🟡 **そろそろ**: 「今日が目安」「あと1日」
     - 🟢 **良好**: 「あと5日」
     - ⚪ **周期なし**: 「5日前に実施」

6. **過去の実施履歴のタイムライン**
   - 詳細画面では、過去にいつ行ったのかの日時・メモが一覧で蓄積。
   - 誤って記録した履歴は個別に削除・取り消しも可能。

7. **初期データはクリーン（空の状態）**
   - 最初から不要なデモデータで散らかることなく、自分の生活リズムに合わせた項目だけをゼロから追加できます。
   - 迷ったときは、空の画面に表示されるおすすめ候補（お風呂掃除、シーツ洗濯、日用品買い出しなど）をワンタップするだけで簡単に作成できます。

8. **完全オフライン動作 & PWA（ホーム画面追加・アプリ化）対応（NEW✨）**
   - **Service Worker (`sw.js`)**: アプリの全リソース（HTML/CSS/JS/アイコン）がローカルに自動キャッシュされ、電波の届かない地下や機内モードでも即座に起動・操作可能。
   - **Web App Manifest (`manifest.json`)**: スマートフォンやPCの「ホーム画面に追加」を行うことで、ブラウザのURLバーが消え、ネイティブアプリ同様のフルスクリーンで利用可能。
   - **完全ローカル保存（IndexedDB）**: すべてのデータは端末内の IndexedDB に保存され、オフラインでも新規作成・完了記録・編集・削除が完全に動作。
   - **リアルタイム接続状況監視**: オフライン時には専用の安心バナーが表示され、復帰時にはトーストでお知らせ。
   - **安心のJSONバックアップ**: ワンクリックで端末に全データを保存・復元可能。

## 🚀 使い方 / 起動方法

### 1. ブラウザで直接開く
フォルダ内の `index.html` をスマートフォンのブラウザ（Safari, Chrome等）またはPCのブラウザで開くだけで即座にご利用いただけます。

### 2. ホーム画面に追加してアプリとして使う（推奨）
- **iOS (Safari)**: 下部の共有ボタン（四角から上矢印）をタップ ➔ 「ホーム画面に追加」
- **Android / Chrome / Edge**: 画面右上のメニュー ➔ 「アプリをインストール」または「ホーム画面に追加」（設定モーダル内の「📲 アプリをインストール」ボタンからも可能）
- インストール後は、オフライン時でもホーム画面のアイコンからいつでも即座に起動できます。
